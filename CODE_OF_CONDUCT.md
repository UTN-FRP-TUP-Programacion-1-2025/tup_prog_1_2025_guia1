# Código de Conducta

Como autor de este proyecto, me comprometo a fomentar un entorno abierto, seguro y respetuoso para cualquier tipo de colaboración.

Se espera que todas las personas que contribuyen, forkean o utilizan este repositorio lo hagan con integridad y buena fe.

## Comportamientos no aceptados

- Usar el código con fines maliciosos, ilegales o no éticos.
- Realizar modificaciones que promuevan contenido ofensivo, violento o dañino.
- Asociar el repositorio original con acciones o declaraciones sin consentimiento del autor.

## Alcance

Este código de conducta aplica a todos los repositorios derivados, issues, pull requests, y otras formas de interacción dentro del ecosistema de este proyecto.

## Reportes

El autor de este repositorio no asume responsabilidad por conductas inapropiadas en forks u otros derivados del proyecto.
